    Joins and reducers¶

    Fan-in joins and the reducers that combine a fork's branch outputs.

    A Join gathers the outputs of a fanned-out subpath and folds them into a single value with a reducer. A reducer takes the running accumulator and one branch's value and returns the next accumulator; built-in reducers cover the common shapes (collect into a list, merge dicts, sum, keep the first). A reducer may instead take a ReducerContext first, giving it the run's state and dependencies and the ability to stop early once it has enough.

    Joins are created through GraphBuilder.collect_node (ordered list collection) and GraphBuilder.reduce_node (any reducer); this module holds the node type and the reducer library they draw on.

    Reducer ¶

    Reducer = Callable[[AccT, ItemT], AccT]

    A fold over branch values: the running accumulator and one value give the next accumulator.

    NormalizedReducer ¶

    AnyJoin ¶

    A join with its type parameters erased, for the executor's wiring layer.

    Stop this fan-in early: emit the accumulator now and drop branches still in flight.

    Join dataclass ¶

    Join(
    id: str,
    item_type: object | None,
    reducer: NormalizedReducer,
    initial_factory: Callable[[], Any],
    ordered: bool,
)

    A fan-in node that folds a fork's branch outputs into one value.

    Created by GraphBuilder.collect_node or GraphBuilder.reduce_node. Wire it as the destination of a fanned-out subpath and as the source of the edge carrying the folded result, which flows on once every branch of the fork has arrived (or a reducer stops early).

    id instance-attribute ¶

    id: str

    Stable identifier of this join node.

    item_type instance-attribute ¶

    item_type: object | None

    The per-branch input type, recorded for build-time edge validation.

    reducer instance-attribute ¶

    reducer: NormalizedReducer

    The fold applied to each branch's value, in context-taking form.

    initial_factory instance-attribute ¶

    initial_factory: Callable[[], Any]

    Builds the accumulator each time the join fires.

    ordered instance-attribute ¶

    ordered: bool

    Whether to fold branches in source order; otherwise in arrival order.
