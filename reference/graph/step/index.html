    Steps¶

    Typed nodes, edges, and the per-invocation context for the graph layer.

    A graph is built from nodes connected by edges. The work-bearing node is a Step: an async unit with one typed input and one typed output. StartNode and EndNode mark where a run begins and ends. Edges name a source and a destination by id.

    A step's own function is fully statically typed (its StepContext.inputs and its return value). The wiring between nodes is validated when the graph is built rather than by the type checker, so the executor treats node inputs and outputs opaquely; see GraphBuilder.build for the build-time checks.

    START_ID module-attribute ¶

    START_ID = '__start__'

    Fixed identifier of every graph's start node.

    END_ID module-attribute ¶

    END_ID = '__end__'

    Fixed identifier of every graph's end node.

    AnyStep ¶

    AnyStep = Step[Any, Any, Any, Any]

    A step with its type parameters erased, for the executor's wiring layer.

    SourceNode ¶

    SourceNode = (
    Step[Any, OutputT, StateT, DepsT]
    | StartNode[OutputT]
    | Join[Any, OutputT]
    | Pause[Any, OutputT]
)

    A node an edge may leave, projected to the output type it emits.

    Lets GraphBuilder.edge_from capture a source node's output type regardless of what input the node accepts.

    DestNode ¶

    DestNode = (
    Step[InputT, Any, StateT, DepsT]
    | EndNode[InputT]
    | Join[InputT, Any]
    | Decision[InputT, StateT, DepsT]
    | Pause[InputT, Any]
)

    A node an edge may enter, projected to the input type it accepts.

    Lets EdgePathBuilder.to require a destination whose input type the source node's output can feed, regardless of what the destination emits.

    StepContext dataclass ¶

    StepContext(
    inputs: InputT,
    state: StateT,
    deps: DepsT,
    emit: Callable[[object], None] = _discard,
    streaming: bool = False,
)

    Bases: Generic[InputT, StateT, DepsT]

    Context passed to a step function on each invocation.

    Carries the node's typed inputs alongside the run-scoped state and the injected deps, both shared across every node in a single run.

    The type parameters, in order, are:

    1. InputT: the type of inputs, the value flowing into this node.
    2. StateT: the type of state, the run-scoped state shared across nodes. Optional; defaults to None when the graph keeps no state.
    3. DepsT: the type of deps, the read-only dependencies injected into nodes (clients, configuration). Optional; defaults to None.

    A step annotates its single parameter with this context; the function's return type is the node's output. The output type is not a parameter here because it lives on the step's return annotation. State and deps may be omitted, so a step with neither annotates StepContext[str].

    Example 
    # this node receives a str, with a Deps bag and no shared state.
async def extract(ctx: StepContext[str, None, Deps]) -> list[Claim]:
    client = ctx.deps.chat_client
    ...

    inputs instance-attribute ¶

    inputs: InputT

    The value flowing into this node along its incoming edge.

    state instance-attribute ¶

    state: StateT

    Run-scoped state shared across nodes for cross-cutting context.

    deps instance-attribute ¶

    deps: DepsT

    Run-scoped dependencies (clients, configuration) injected into nodes.

    emit class-attribute instance-attribute ¶

    emit: Callable[[object], None] = _discard

    Emit a progress datum from inside this node while it runs.

    Call it with any value to surface that value as a NodeEmitted event tagged with this node, for instance to forward chat token fragments as they arrive. The datum is forwarded only when the run sets stream_node_data on RunOptions; otherwise it is discarded, so a node can emit unconditionally at no cost when nothing observes it.

    streaming class-attribute instance-attribute ¶

    streaming: bool = False

    Whether emitted data is observed on this run.

    True only when the run sets stream_node_data on RunOptions. A node that can stream partial results (for instance through a component's on_partial hook) should do so only when this is set, and take its cheaper one-shot path otherwise.

    Step dataclass ¶

    Step(
    id: str,
    call: Callable[
        [StepContext[InputT, StateT, DepsT]],
        Awaitable[OutputT],
    ],
    input_type: object | None,
    output_type: object | None,
    retries: int = 0,
    retry_backoff: float = 0.0,
    timeout: float | None = None,
)

    A typed async node: one input value in, one output value out.

    Created by GraphBuilder.step_node (usually as the @g.step_node decorator), then referenced when wiring edges. The recorded input_type and output_type are read from the wrapped function's annotations and used to validate edge compatibility at build time.

    id instance-attribute ¶

    id: str

    Stable identifier, supplied to step_node or taken from the function's name.

    call instance-attribute ¶

    call: Callable[
    [StepContext[InputT, StateT, DepsT]], Awaitable[OutputT]
]

    The async function this node runs.

    input_type instance-attribute ¶

    input_type: object | None

    The declared input type, or None when it could not be read.

    output_type instance-attribute ¶

    output_type: object | None

    The declared output type, or None when it could not be read.

    retries class-attribute instance-attribute ¶

    retries: int = 0

    How many extra attempts to make after the first if the call fails.

    Must be non-negative.

    retry_backoff class-attribute instance-attribute ¶

    retry_backoff: float = 0.0

    Base seconds to wait before a retry; the wait doubles each further attempt.

    Must be non-negative.

    timeout class-attribute instance-attribute ¶

    timeout: float | None = None

    Seconds a single attempt may run before it is cancelled, or None for no limit.

    Must be positive when set.

    StartNode dataclass ¶

    StartNode(id: str = START_ID)

    The graph's entry node; the graph's input value flows out of it.

    Its type parameter is the graph input type, matched against the first step's input type when wiring the entry edge.

    id class-attribute instance-attribute ¶

    id: str = START_ID

    Fixed start-node identifier.

    EndNode dataclass ¶

    EndNode(id: str = END_ID)

    The graph's terminal node; the value routed into it is the graph output.

    Its type parameter is the graph output type, matched against the last step's output type when wiring the exit edge.

    id class-attribute instance-attribute ¶

    id: str = END_ID

    Fixed end-node identifier.

    EdgeKind ¶

    Bases: StrEnum

    How an edge delivers its source node's output to its destination.

    PLAIN class-attribute instance-attribute ¶

    PLAIN = 'plain'

    Deliver the whole output as one value to the destination.

    MAP class-attribute instance-attribute ¶

    MAP = 'map'

    Fan an iterable output out to one parallel branch per item.

    source_id: str

    Identifier of the node the edge leaves.
