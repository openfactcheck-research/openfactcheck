    DevVerifier class¶

    Dev bypass verifier that returns the same user on every call, without validating the token.

    DEV_USER module-attribute ¶

    DEV_USER = AuthUser(
    sub="dev-user-00000000",
    email="dev@localhost",
    name="Dev User",

    User returned by DevVerifier on every call.

    DevVerifier ¶

    Bypass verifier for local development.

    Returns DEV_USER on every call, without validating the token.

    Warning

    Never use in production.
