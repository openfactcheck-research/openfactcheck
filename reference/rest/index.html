    OpenFactCheck API 2.0.0a9¶

    HTTP reference for the OpenFactCheck server.

    • Interactive sandbox: live Swagger UI at /docs, ReDoc at /redoc.
    • Auth: every non-health endpoint expects an Authorization: Bearer <token> header.
    • Errors: failures return a structured JSON body with detail, code, and status fields.

    WorkspaceResponse¶

    Name Type Description
    content Pipeline configuration as a JSON object. ``None`` for an empty workspace.
    created_at string(date-time) Timestamp the workspace was created.
    description string Freeform workspace description.
    id string Opaque unique identifier for the workspace.
    locked boolean When ``True``, the workspace is read-only.
    name string Human-readable workspace name.
    project_id string Identifier of the project the workspace belongs to.
    settings WorkspaceSettings Workspace-level configuration.
    sort_order integer Ordering hint for display; lower values appear first.
    updated_at string(date-time) Timestamp of the most recent modification.
