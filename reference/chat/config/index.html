    Chat configuration¶

    Model and runtime configuration for the chat layer.

    Build a provider-specific configuration (for example OpenAIConfig), optionally pair it with a RuntimeConfig for execution-level settings, and pass both to ChatClient.

    ModelConfig is the union of every provider configuration; callers that must work with any provider accept a ModelConfig and branch on config.provider.

    Example 
    from openfactcheck.chat import ChatClient, OpenAIConfig
from openfactcheck.messages import UserMessage

client = ChatClient(config=OpenAIConfig(model="gpt-4o", temperature=0.2))
response = client.completion([UserMessage(content="Hello")])

    Base¶

    BaseModelConfig ¶

    Bases: BaseModel

    Common parameters shared across every provider config.

    Not instantiated directly; use a provider-specific subclass.

    model instance-attribute ¶

    model: str

    Identifier of the model to call, for example "gpt-4o".

    temperature class-attribute instance-attribute ¶

    temperature: float | None = None

    How random the model's output is. Lower values are more focused, higher values more varied.

    max_output_tokens class-attribute instance-attribute ¶

    max_output_tokens: int | None = Field(default=None, gt=0)

    Cap on the number of tokens the model may generate in its response.

    Must be positive.

    top_p class-attribute instance-attribute ¶

    top_p: float | None = Field(default=None, ge=0.0, le=1.0)

    Nucleus sampling cutoff.

    Range [0.0, 1.0].

    OpenAICompatibleConfig ¶

    Bases: BaseModelConfig

    Sampling parameters shared by OpenAI-compatible provider configs.

    Not instantiated directly; a concrete subclass adds its own provider discriminator.

    temperature class-attribute instance-attribute ¶

    temperature: float | None = Field(
    default=None, ge=0.0, le=2.0
)

    How random the model's output is. Lower is more focused, higher more varied.

    Range [0.0, 2.0].

    seed class-attribute instance-attribute ¶

    seed: int | None = None

    Request reproducible sampling. Determinism is best-effort, not guaranteed.

    frequency_penalty class-attribute instance-attribute ¶

    frequency_penalty: float | None = Field(
    default=None, ge=-2.0, le=2.0
)

    Penalize tokens by how often they have already appeared. Positive values reduce repetition.

    Range [-2.0, 2.0].

    presence_penalty class-attribute instance-attribute ¶

    presence_penalty: float | None = Field(
    default=None, ge=-2.0, le=2.0
)

    Penalize tokens that have already appeared at all. Positive values encourage novelty.

    Range [-2.0, 2.0].

    reasoning_effort class-attribute instance-attribute ¶

    reasoning_effort: (
    Literal["low", "medium", "high"] | None
) = None

    Reasoning budget hint. Ignored by non-reasoning models.

    Provider configs¶

    OpenAIConfig ¶

    Bases: OpenAICompatibleConfig

    Configuration for an OpenAI model.

    Example 
    config = OpenAIConfig(
    model="gpt-4o",
    temperature=0.2,
    max_output_tokens=500,
)

    provider class-attribute instance-attribute ¶

    provider: Literal['openai'] = 'openai'

    Identifies this configuration as OpenAI's.

    OpenRouterConfig ¶

    Bases: OpenAICompatibleConfig

    Configuration for a model served through OpenRouter.

    OpenRouter exposes an OpenAI-compatible Chat Completions API. Address a model by its namespaced OpenRouter id, for example "openai/gpt-4o" or "anthropic/claude-sonnet-4".

    Example 
    config = OpenRouterConfig(
    model="anthropic/claude-sonnet-4",
    temperature=0.2,
    max_output_tokens=500,
)

    provider class-attribute instance-attribute ¶

    provider: Literal['openrouter'] = 'openrouter'

    Identifies this configuration as OpenRouter's.

    AnthropicConfig ¶

    Bases: BaseModelConfig

    Configuration for an Anthropic model.

    Example 
    config = AnthropicConfig(
    model="claude-sonnet-4-6",
    temperature=0.4,
    thinking=True,
    thinking_budget_tokens=4000,
)

    provider class-attribute instance-attribute ¶

    provider: Literal['anthropic'] = 'anthropic'

    Identifies this configuration as Anthropic's.

    temperature class-attribute instance-attribute ¶

    temperature: float | None = Field(
    default=None, ge=0.0, le=1.0
)

    How random the model's output is. Lower is more focused, higher more varied.

    Range [0.0, 1.0].

    top_k class-attribute instance-attribute ¶

    top_k: int | None = Field(default=None, gt=0)

    Sample from the top-k tokens at each step.

    Must be positive.

    thinking class-attribute instance-attribute ¶

    thinking: bool = False

    Enable extended thinking so the model can show its reasoning before answering.

    thinking_budget_tokens class-attribute instance-attribute ¶

    thinking_budget_tokens: int | None = Field(
    default=None, gt=0
)

    How many tokens the model may spend on the reasoning trace.

    Only set when thinking=True. Must be positive.

    Union type¶

    ModelConfig ¶

    ModelConfig = Annotated[
    OpenAIConfig | AnthropicConfig | OpenRouterConfig,
    Discriminator("provider"),
]

    Union of every provider configuration.

    Accept this type in code that must work with any provider; branch on config.provider to distinguish the concrete subclass.

    Runtime¶

    RuntimeConfig ¶

    Bases: BaseModel

    Execution-level settings for a chat request.

    Example 
    runtime = RuntimeConfig(timeout=30.0, max_retries=5)

    timeout class-attribute instance-attribute ¶

    timeout: float | None = Field(default=None, gt=0)

    Per-request timeout in seconds.

    Must be positive. Unset uses the SDK default.

    max_retries class-attribute instance-attribute ¶

    max_retries: int = Field(default=2, ge=0)

    Automatic retries on transient failures.

    Set to 0 to disable. Must be non-negative.

    max_parse_retries class-attribute instance-attribute ¶

    max_parse_retries: int = Field(default=0, ge=0)

    Reprompts allowed when a structured-output reply fails validation.

    Applies only to ChatClient.completion_as and its async peer. 0 raises on the first validation failure; a positive value re-sends the validation error to the model up to that many times before raising. Distinct from max_retries, which retries transport failures. Must be non-negative.
