    Responses¶

    Response types for the chat layer.

    Non-streaming calls (ChatClient.completion and ChatClient.acompletion) return a ChatResponse. Streaming calls (ChatClient.stream and ChatClient.astream) yield a sequence of StreamEvent values ending with a StreamEnd that carries the final FinishReason and token Usage.

    Example 
    from openfactcheck.chat import (
    ChatClient,
    OpenAIConfig,
    StreamEnd,
    TextDelta,
)
from openfactcheck.messages import UserMessage

client = ChatClient(config=OpenAIConfig(model="gpt-4o"))

# Non-streaming.
response = client.completion([UserMessage(content="Hello")])
print(response.message.content)

# Streaming.
for event in client.stream([UserMessage(content="Tell me a joke")]):
    match event:
        case TextDelta(content=chunk):
            print(chunk, end="")
        case StreamEnd(finish_reason=reason):
            print()
            print(f"done: {reason}")

    Non-streaming¶

    ChatResponse ¶

    Bases: BaseModel

    Complete response from a non-streaming model call.

    Example 
    response = client.completion([UserMessage(content="Hello")])
print(response.message.content, response.usage.output_tokens)

    message instance-attribute ¶

    message: AssistantMessage

    The model's reply.

    model instance-attribute ¶

    model: str

    Identifier of the model that produced the response, e.g. "gpt-4o".

    provider instance-attribute ¶

    provider: ProviderName

    Provider that served the response.

    usage class-attribute instance-attribute ¶

    usage: Usage | None = None

    Token counts, or None when the provider didn't report usage.

    finish_reason class-attribute instance-attribute ¶

    finish_reason: FinishReason | None = None

    Why the model stopped, or None when the provider didn't report a reason.

    Usage ¶

    Bases: BaseModel

    Token usage reported by a single model call.

    input_tokens instance-attribute ¶

    input_tokens: int

    Tokens consumed by the prompt.

    output_tokens instance-attribute ¶

    output_tokens: int

    Tokens generated in the response.

    FinishReason ¶

    Bases: StrEnum

    Why the model stopped generating.

    Values correspond to stop reasons reported by every supported provider, normalized into a single enum.

    STOP class-attribute instance-attribute ¶

    STOP = 'stop'

    Natural stop: the model decided the response was complete.

    TOOL_CALLS class-attribute instance-attribute ¶

    TOOL_CALLS = 'tool_calls'

    The model emitted tool calls and is waiting for their results before continuing.

    LENGTH class-attribute instance-attribute ¶

    LENGTH = 'length'

    Response was truncated to honor max_output_tokens or the provider's maximum.

    CONTENT_FILTER class-attribute instance-attribute ¶

    CONTENT_FILTER = 'content_filter'

    Response was blocked or truncated by the provider's content policy.

    ERROR class-attribute instance-attribute ¶

    ERROR = 'error'

    Generation aborted due to a provider or transport error.

    Streaming events¶

    TextDelta ¶

    Bases: BaseModel

    A text fragment arriving during a streaming call.

    Concatenate every TextDelta.content in emission order to reconstruct the final message body.

    type class-attribute instance-attribute ¶

    type: Literal['text'] = 'text'

    Event tag identifying this as a text chunk.

    content instance-attribute ¶

    content: str

    Text fragment from the model.

    StreamEnd ¶

    Bases: BaseModel

    Terminal event for a stream. Carries completion metadata.

    Always emitted exactly once as the last event in the stream, even on non-stop terminations.

    type class-attribute instance-attribute ¶

    type: Literal['end'] = 'end'

    Event tag identifying this as the stream terminator.

    finish_reason class-attribute instance-attribute ¶

    finish_reason: FinishReason | None = None

    Why the model stopped, or None when the provider didn't report a reason.

    usage class-attribute instance-attribute ¶

    usage: Usage | None = None

    Token counts, or None when the provider didn't report usage.

    StreamEvent module-attribute ¶

    StreamEvent = Annotated[
    TextDelta | StreamEnd, Discriminator("type")
]

    Events yielded by streaming calls.

    StreamEnd is always the last event; every event before it is a TextDelta.
